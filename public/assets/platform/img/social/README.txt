Share-card banner used by any app that has no banner of its own (the picture LinkedIn, Slack, X, WhatsApp etc.
show when a link to it is pasted).

Drop ONE file here named  default.jpg  (or default.jpeg / default.png / default.webp).
Recommended: 1200 x 630 px, under 1 MB. No code change is needed; in production
run `php scripts/publish-assets.php` after adding or replacing it.
